# What the F1TENTH gym (ADR-0032) needs that the image doesn't already have,
# pinned so every image gets the same. The Dockerfile installs these and the
# gym itself (from git at a fixed commit: it isn't on PyPI) with --no-deps,
# so pip never changes a package already in /opt/venv, then runs `pip check`:
# a gym dependency the image doesn't satisfy fails the build (except the gym's
# opencv-python < 5, which the venv's Zephyr-installed 5.x doesn't meet).
#
# Left to the image, which installs them earlier into the same venv (Zephyr's
# requirements, the ICD generators; Ubuntu's for PyYAML): numpy (2.x; numba
# 0.68 needs < 2.6), PyYAML, requests and what it needs, typing_extensions,
# mypy_extensions, and opencv-python (cv2). Pinning them here would fight
# those installs. Nothing the gym backend runs imports cv2: only the gym's
# renderer does.
#
# Every package here has wheels for linux amd64 and arm64 (ADR-0050), and no
# release was less than 14 days old when pinned: a fresh upload has had no
# time to be yanked or flagged.
# To update: change a pin, rebuild the image, run `npx nx test ros`.
