## Routing

The site uses Next.js App Router. Every folder inside `app/` with a `page.tsx` becomes a route.

```
app/
├── page.tsx              →  /
├── robots/page.tsx       →  /robots
├── team/page.tsx         →  /team
├── governance/page.tsx   →  /governance
├── contact/page.tsx      →  /contact
├── blueprint/page.tsx    →  /blueprint
└── layout.tsx            →  root layout (fonts, providers)
```

### Adding a new page

1. Create a folder inside `app/` with the route name
2. Add a `page.tsx` inside it
3. Add the route to `NAV_ITEMS` in `components/layout/Header.tsx` if it belongs in the nav

```tsx
// components/layout/Header.tsx
const NAV_ITEMS = [
  { label: 'HOME',       href: '/' },
  { label: 'ROBOTS',     href: '/robots' },
  { label: 'TEAM',       href: '/team' },
  { label: 'GOVERNANCE', href: '/governance' },
  { label: 'CONTACT',    href: '/contact' },
  // add your new route here
] as const;
```

## Page Anatomy

Every page follows the same shell:

```tsx
'use client';

import Header from '@/components/layout/Header';
import Footer from '@/components/layout/Footer';
import BlueprintGrid from '@/components/ui/BlueprintGrid';

export default function MyPage() {
  return (
    <>
      <Header />
      <main>
        <section className="relative px-6 pt-28 md:px-10 lg:px-16">
          <BlueprintGrid variant="hero" />
          {/* your content */}
        </section>
      </main>
      <Footer />
    </>
  );
}
```

Key points:
- `'use client'` is required on pages that use hooks or animations
- `pt-28` offsets content below the fixed header (~72px tall)
- `BlueprintGrid` renders the subtle background grid. Use `variant="hero"` on the first section and `variant="section"` on subsequent ones
- `px-6 md:px-10 lg:px-16` is the standard horizontal padding — keep it consistent

## Scroll Reveal Animations

Two hooks handle entrance animations via GSAP ScrollTrigger:

```tsx
import { useScrollReveal, useStaggerReveal } from '@/hooks/useScrollReveal';

// Fade + slide a single element when it enters the viewport
const ref = useScrollReveal<HTMLDivElement>({ y: 30, delay: 0.1 });

// Stagger-reveal multiple children matching a selector
const gridRef = useStaggerReveal<HTMLDivElement>('[data-reveal-item]', {
  stagger: 0.1,
});
```

Both hooks respect `prefers-reduced-motion` — they skip the animation entirely for users who have that set.

## Data Files

All editable content lives in `data/`. These are plain TypeScript files — no CMS, no API.

```
data/
├── projects.ts    # Robots page cards
├── team.ts        # Team page exec grid
└── sponsors.ts    # Home page sponsor logos
```

See [Updating Content](./content.mdx) for details on each file.

## TransitionLink

Use `TransitionLink` instead of Next.js `Link` for internal navigation. It triggers the page transition animation before pushing the route.

```tsx
import TransitionLink from '@/components/ui/TransitionLink';

<TransitionLink href="/robots">Our Robots</TransitionLink>
```

`<a>` tags with external `href` are fine to use directly for external links.

## Root Layout

`app/layout.tsx` loads fonts and wraps the app in `ClientProviders` (`components/providers/`):

```tsx
// Fonts loaded: Chakra Petch (headings), Inter (body), JetBrains Mono (mono)
// ClientProviders: TransitionProvider (page transitions), with the LoadingScreen inside it
```

`ClientProviders` renders the `LoadingScreen` inside `TransitionProvider`. It shows on first load only and slides away automatically.
