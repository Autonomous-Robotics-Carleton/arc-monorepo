The ARC website (`apps/web`) is the public-facing club site. It lives in the monorepo alongside the docs site and any other apps.

## Tech Stack

| Layer | Tool | Version |
|---|---|---|
| Framework | Next.js (App Router) | 15 |
| Styling | Tailwind CSS | v4 |
| Language | TypeScript | 5 |
| Animation | GSAP + ScrollTrigger | 3 |
| Package manager | pnpm (monorepo) | — |

### Why these choices

**Next.js App Router** — server components by default, file-based routing, zero-config image optimisation. Every page uses `'use client'` today since most have animations, but the structure is ready for server components where it makes sense.

**Tailwind v4** — uses a `@theme` block in `globals.css` instead of a separate config file. All design tokens live there as CSS custom properties. This means you can reference them in both Tailwind classes *and* raw CSS/inline styles.

**GSAP** — used for the blueprint exploded view scroll scene and scroll-triggered entrance animations. A shared `lib/animations.ts` wrapper handles registration and reduced-motion checks.

## Running Locally

```bash
# From the monorepo root
pnpm install
npx nx dev web
```

The site starts at `http://localhost:3001` (the docs site uses 3000).

<Callout type="info" title="Port conflict?">
The port is fixed, so if 3001 is taken `nx dev web` fails: stop the other process. `nx dev docs` uses 3000 and moves to the next free port if 3000 is busy, which can take 3001, so start web first.
</Callout>

## Pages at a Glance

| Route | Purpose |
|---|---|
| `/` | Home — hero, identity, mission, sponsors |
| `/robots` | Project cards with click-to-expand modal |
| `/team` | Exec grid + Instagram feed + join CTA |
| `/governance` | Constitution, meeting minutes, current status |
| `/contact` | Email, location, socials, GitHub, docs |
| `/blueprint` | Easter egg — GSAP scroll exploded car view |
| `/projects` | An older copy of `/robots` without the modal; not in the nav |

## Key Directories

```
apps/web/
├── app/                  # Next.js routes (one folder = one route)
├── components/
│   ├── layout/           # Header, Footer
│   ├── sections/         # Page-specific sections (BlueprintExplode, LoadingScreen)
│   └── ui/               # Shared UI primitives
├── context/              # TransitionContext (page transition system)
├── data/                 # Content data files — edit these to update page content
├── hooks/                # useScrollReveal, useStaggerReveal
├── lib/                  # animations.ts GSAP wrapper
└── public/               # Static assets (car.png, part PNGs)
```
