The Team page shows a live Instagram feed from `@arcarleton` using [Behold.so](https://behold.so) as the data layer. Behold fetches posts from the Instagram API and exposes them as a simple JSON endpoint — no OAuth in our app, no iframes, full control over the UI.

## How it works

1. Behold connects to the `@arcarleton` Instagram account
2. It creates a feed and gives you a URL like `https://feeds.behold.so/YOUR_FEED_ID`
3. Our `InstagramFeed` component fetches that URL and renders the posts as cards
4. If no feed ID is set, it shows 6 placeholder cards instead

## Setup

<Steps>
  <Step>
    ### Create a Behold account
    Go to [behold.so](https://behold.so) and sign up. The free tier is sufficient for a club site.
  </Step>
  <Step>
    ### Connect Instagram
    In the Behold dashboard, click **Connect Instagram** and log in with the `@arcarleton` account credentials. Whoever manages the Instagram account will need to do this step.
  </Step>
  <Step>
    ### Create a feed
    Click **New Feed**, give it a name (e.g. "ARC Website"), and save. Behold will start syncing posts.
  </Step>
  <Step>
    ### Copy the feed ID
    In the feed settings, copy the **Feed ID** — it looks like a random string of characters.
  </Step>
  <Step>
    ### Add it to the codebase
    Open `apps/web/app/team/page.tsx` and paste the feed ID:

    ```ts
    // Near the top of the file
    const BEHOLD_FEED_ID = 'paste-your-feed-id-here';
    ```

    That's it. The `InstagramFeed` component will start fetching and rendering real posts.
  </Step>
</Steps>

<Callout type="info" title="Free tier limits">
Behold's free tier refreshes the feed periodically (not real-time). For a club site this is perfectly fine — posts will appear within a few hours of being published.
</Callout>

## What gets displayed

The component fetches the 6 most recent posts. Each card shows:
- The post image (or video thumbnail for video posts)
- The first two lines of the caption
- A **VIEW POST →** link to the post on Instagram

The **VIEW POST →** link opens the post on Instagram in a new tab; the rest of the card isn't a link.

## The component (`components/ui/InstagramFeed.tsx`)

```ts
type BeholdPost = {
  id: string;
  mediaUrl: string;       // full image URL
  thumbnailUrl?: string;  // video thumbnail (use this if present)
  permalink: string;      // instagram.com/p/...
  caption?: string;
};
```

The component fetches from `https://feeds.behold.so/${feedId}`, parses the response as an array of `BeholdPost` objects, and slices to the first 6. If the fetch fails (network error, invalid ID), it silently falls back to placeholder cards.

## Troubleshooting

**Posts not showing up after adding the feed ID:**
- Check the browser console for network errors on the Behold URL
- Make sure the feed ID is correct (no extra spaces)
- The Behold free tier may take a few minutes to sync on first connect

**Images not loading:**
- Images are plain `<img>` tags loaded from Behold's CDN (not `next/image`, so `next.config.mjs` doesn't apply). Check the browser's network tab for blocked or expired URLs

**Account disconnected:**
- Instagram sessions expire. Log back into Behold and reconnect the Instagram account
