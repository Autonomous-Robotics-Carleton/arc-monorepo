The Team page shows a live Instagram feed from `@arcarleton` using [Behold.so](https://behold.so) as the data layer. Behold fetches posts from the Instagram API and exposes them as a simple JSON endpoint — no OAuth in our app, no iframes, full control over the UI.

## How it works

1. Behold connects to the `@arcarleton` Instagram account (the *source*)
2. A Behold *feed* exposes that account's latest posts as JSON at `https://feeds.behold.so/<feed ID>`
3. The site's route `app/api/instagram/route.ts` fetches that JSON on the server, keeps only what the cards need, and caches it for 6 hours
4. `InstagramFeed` reads `/api/instagram` and renders the posts as cards; with no posts, it shows a "follow us" panel instead

The site's feed is **ARC** in the Behold dashboard (signed in as the club's account), and its ID is `BEHOLD_FEED_ID` in `apps/web/data/social.ts`.

<Callout type="info" title="Why the server route">
Behold's free plan counts every feed request as a view, with 1,200 a month. Fetching from each visitor's browser would spend one view per page load. The server route fetches at most once every 6 hours, about 120 views a month however busy the site is. Change `revalidate` on the route's `fetch` to trade freshness against views. The route is dynamic, so builds (CI, Docker) never call Behold.
</Callout>

## Setting up a new feed

<Steps>
  <Step>
    ### Connect the account
    In the [Behold dashboard](https://app.behold.so), go to **Sources** and connect `@arcarleton` (whoever manages the Instagram account logs in).
  </Step>
  <Step>
    ### Create a feed
    **Feeds → Add Feed**: content type **User**, then click **Source** and pick `@arcarleton` in the pop-up. Output type can be **JSON** or **Widget**: both serve the same JSON, and the site ignores the widget styling.
  </Step>
  <Step>
    ### Add the ID
    Copy the ID from the feed's URL (`app.behold.so/feeds/<feed ID>`) into `apps/web/data/social.ts`:

    ```ts
    export const BEHOLD_FEED_ID = 'paste-your-feed-id-here';
    ```
  </Step>
</Steps>

## What gets displayed

The home page shows the 3 latest posts and the Team page 6 (the `count` prop). Each card shows:
- The post image: Behold's 700px WebP (`sizes.medium`), or the thumbnail for videos
- The first two lines of the caption, without hashtags (`prunedCaption`)
- **View on Instagram**

The whole card links to the post on Instagram, in a new tab. Placeholder cards show while the feed loads.

## The route (`app/api/instagram/route.ts`)

Current (v2) Behold feeds return an object with a `posts` array; older feeds return the array itself, and both are handled. The route returns `{ posts: [{ id, permalink, image, caption }] }`. If Behold fails or there's no feed ID, it returns no posts and the page shows the follow-us panel.

## Troubleshooting

**Posts not showing up after adding the feed ID:**
- Open `/api/instagram` on the site: it should list the posts. Remember it's cached for up to 6 hours after a deploy
- Make sure the feed ID is correct (no extra spaces)
- The Behold free tier may take a few minutes to sync on first connect

**Images not loading:**
- Images are plain `<img>` tags loaded from Behold's CDN (not `next/image`, so `next.config.mjs` doesn't apply). Check the browser's network tab for blocked or expired URLs

**Account disconnected:**
- Instagram sessions expire. Log back into Behold and reconnect the Instagram account
