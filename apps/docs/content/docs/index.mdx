---

![ARC banner](/images/arcbanner.png)

The car is a 4WD autonomy research platform: a sandbox where the team's engineers try ideas in software without building hardware first. Classical autonomy comes first (state estimation, localization, planning, MPC), then learned and embodied-AI policies. It's sized to race under F1TENTH/Roboracer rules.

Everything about the car is decided and recorded in [`systems/`](../../../../systems/README.md). Start with the [architecture overview](../../../../systems/architecture.md), and read [How these docs work](../../../../systems/README.md) to make sense of the IDs (`SYS-05`, `ADR-0012`, …) you'll see everywhere.
