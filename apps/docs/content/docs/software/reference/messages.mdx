## Sync link and controller telemetry

Source: [`systems/icd/sync-link.xml`](../../../../../../systems/icd/sync-link.xml), MAVLink 2 with our own message set (ADR-0031). The sync link between the sync MCU and the Orin ([interface](../../../../../../systems/icd/sync-link.md)) and each motor controller's telemetry UART ([interface](../../../../../../systems/icd/controller-telemetry.md)) share this message set: a controller sends `ARC_MOTOR_STATUS` and `ARC_LINK_STATUS`.
